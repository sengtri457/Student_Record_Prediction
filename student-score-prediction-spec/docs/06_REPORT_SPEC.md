# 06. Report Spec

File: `reports/final_report.md` (export to PDF if needed).
Length: 6 to 12 pages equivalent. Plain language. Short sentences.

## Sections

1. **Introduction**: problem, why it matters, goal
2. **Data**: source, size, columns, how collected, consent, limits
3. **Data cleaning**: what was wrong, what was done, counts
4. **Missing values**: table plus reasoning
5. **Descriptive statistics**: table plus short reading
6. **Exploratory analysis**: the 5+ figures, each with 2 to 3 sentences
7. **Patterns and relationships**: answers to the 7 EDA questions
8. **Modeling setup**: target, features, preprocessing, 80/20 split, models
9. **Results**: comparison table, residual and actual vs predicted charts
10. **Model selection**: which model, which rule, why
11. **Explanation**: coefficients, feature importance, plain summary
12. **Predictions**: test sample plus custom students
13. **Limitations**: sample size, self reported data, missing features, no causation
14. **Conclusion and next steps**
15. **Appendix**: config, environment, how to reproduce

## Style rules

- Every figure has a caption and is referenced in the text.
- Every number comes from a saved table. No typing numbers by hand.
- Say "is associated with", not "causes".
- Be honest. If Random Forest did not win, say so.
